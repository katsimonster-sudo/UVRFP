# FP 2025 Project Rules

## 🔒 Scope & Safety Constraints
1. **Target Working Directory**: Працювати **виключно** всередині директорії `r:\Скани\2022\2022_05_04\FP 2025` (та її підкаталогах).
2. **Strict Boundary**: Заборонено виходити за межі папки `r:\Скани\2022\2022_05_04\FP 2025`.
3. **No File Deletion / Modification Outside Scope**: Категорично заборонено видаляти, переміщувати або змінювати будь-які файли чи папки за межами цієї папки (зокрема сусідні `my site WoodEx`, `my site` тощо).
4. **All Commands Execution**: Усі термінальні команди, збірки, скрипти та робочі процеси повинні запускатися з поточною робочою директорією (CWD) всередині `r:\Скани\2022\2022_05_04\FP 2025`.
5. **Git Version Control**: Репозиторій підключено до `https://github.com/katsimonster-sudo/UVRFP.git` (гілка `main`). Після кожного виконаного завдання або важливих змін обов'язково робити `git commit` та `git push` до віддаленого репозиторію.
