# FP-2025 Studio — Автоматизація виконання фінансового плану

**Підприємство:** ДП "ОК "Укрвуглереструктуризація"  
**Призначення:** Автоматизація обробки відсканованих звітів бухгалтерії та формування комплексної звітності про виконання фінансового плану до Міністерства енергетики України.

---

## 📋 Комплект звітності (10 аркушів у підсумковому Excel-файлі)

Файл книги `Звіт_Викон_Фін_Пл_за_N_кв_2026.xlsx` містить:
1. **`580`:** Зведений звіт про виконання фінплану (EBITDA, фінрезультати, коефіцієнтний аналіз рентабельності, ліквідності та стійкості, балансові статті).
2. **`581`:** Виконання I. Формування фінансових результатів (доходи, витрати) та детальні елементи операційних витрат (сировина, паливо, зарплата, ЄСВ, амортизація).
3. **`582`:** Виконання II. Розрахунки з бюджетом (розподіл прибутку/збитку з прив'язкою до ряд. 14201 Балансу, податки до держбюджету, ЄСВ).
4. **`583`:** Виконання III. Рух грошових коштів (операційна, інвестиційна, фінансова діяльність).
5. **`584`:** Виконання IV. Капітальні інвестиції *(шаблон із формулами підсумків SUM)*.
6. **`588`:** Виконання. Джерела капітальних інвестицій *(шаблон із формулами підсумків SUM)*.
7. **`589`:** Виконання розшифровок до фінплану (деталізація операційних доходів і витрат, бюджетне фінансування ліквідації шахт за КЕКВ 2610).
8. **`5895`:** Персонал, чисельність та фонд оплати праці (штат, АУП, робітники, середня зарплата).
9. **`Дані_ПДФ`:** Структурований архів первинних показників зі сканів для прозорого аудиту кожної цифри.
10. **`Перевірка`:** Зведена таблиця контрольних рівностей (Активи = Пасиви, Рух коштів, Збиток, Відповідність розшифровок підсумкам).

## 🚀 Швидкий запуск

У терміналі всередині папки проєкту:

```bash
# 1. Запуск локального веб-сервера
npm start
```

Після запуску відкрийте у будь-якому браузері:  
👉 **`http://localhost:3000`**

---

## 🛠️ Як працювати в інтерфейсі

1. **Завантаження скану:** Натисніть кнопку **«📁 Завантажити скан PDF»** та оберіть файл (наприклад, `3квЛМ001.pdf` або скан 4-го кварталу).
2. **Перевірка у Split-View:**
   - **Ліворуч:** ви бачите оригінальні сторінки скану з перемикачем сторінок.
   - **Праворуч:** 10 вкладок робочої книги (`580`, `581`, `582`, `583`, `584`, `588`, `589`, `5895`, `Дані_ПДФ`, `Перевірка`).
3. **Редагування:** Якщо якась цифра у скані була змазана, ви можете підправити її безпосередньо у веб-таблиці — квартальна дельта та контрольні суми перерахуються автоматично.
4. **Експорт у Excel:** Натисніть кнопку **«📥 Експорт в Excel (.xlsx)»** — система миттєво згенерує та завантажить готовий до подання файл з усіма активними формулами.
